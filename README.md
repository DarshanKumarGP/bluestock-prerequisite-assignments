# Bluestock Prerequisite Assignments

Week 1 and Week 2 coursework for the Bluestock Fintech Data Analyst Internship prerequisite program.

## Week 1 — Core Data Analytics Foundation
Excel dashboard, SQL practice queries, Python data analysis notebook, EDA report, Power BI dashboard.

## Week 2 — FinTech Domain & Software Development Fundamentals
Stock market summary, financial statement analysis, REST API extraction assignment, software architecture diagram, FinTech research report.
